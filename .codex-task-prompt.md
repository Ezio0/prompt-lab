# Codex Task: Prompt Lab v1.0 — Full Implementation

## What to build

Prompt Lab is a CLI tool for LLM prompt version management and A/B testing. Developers register prompt versions, define test cases (ideal-state + bad-case), run A/B comparisons, and view structured reports to make data-driven decisions.

## Rules

1. **TDD for every task** — write failing test first → verify it fails → implement → verify it passes
2. **One commit per task** — commit message format: `feat(task-name): description` (e.g., `feat(scaffold): project structure + CLI entry point`)
3. **Do NOT run `git push`** — just commit locally
4. **Python ≥3.11** — use modern type hints (`str | None`, not `Optional[str]`)
5. **Dependencies**: `click` (CLI), `httpx` (HTTP client), `pyyaml` (config), `rich` (terminal tables), `pytest` + `pytest-asyncio` + `pytest-cov` (dev)
6. **Package structure**: `prompt_lab/` (main package), `prompt_lab/core/` (core modules), `prompt_lab/cli.py` (CLI entry)
7. **All data stored as files** under `.prompt-lab/` — no database
8. **Provider uses OpenAI-compatible API** — POST to `/chat/completions`
9. **Do NOT create a `.env` file** — API keys come from environment variables only
