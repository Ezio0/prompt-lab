# Prompt Lab 产品定位

**项目名称**: Prompt Lab
**日期**: 2026-07-25
**版本**: v1.0

---

## WHO

在 LLM 应用项目中调 prompt 的开发者，以及需要改 prompt 的非技术角色（PM、运营）。

典型场景：一个开发者搭好了 LLM 应用，prompt 跑在生产环境里。某天发现了 bad case，或者想精简 prompt 降低 token 消耗。他改了 prompt 文字，但不知道新版输出质量有没有退化——只能肉眼扫几条，感觉差不多就上线。他身边的 PM 也想改 prompt 里的输出风格，但不会跑代码，只能把想法丢给开发者代劳。

## WHY

改 prompt 很随意，没有版本管理和 A/B 测试，效果好坏全靠猜。

痛点独立于任何工具存在：开发者在生产环境里改 prompt 字符串，改完之后没有验证集对比，没有版本回溯，没有量化指标。效果可能变好，也可能变差非常多——然后又得重新改。这不是个别现象，是当前所有 LLM 应用团队的日常。

## WHY NOW

三个变化叠加，让这件事今天重要、3 年前不重要：

1. **LLM 应用 2023 年才真正爆发** — 3 年前没有大量团队在生产环境用 LLM，prompt 作为"软件资产"的概念不存在。改 prompt 随意是因为那时候 prompt 本身就是实验脚本。

2. **模型供应商频繁变更，参数互相影响** — 模型升级（如 DeepSeek 默认开 thinking mode 导致 content 返回空）、参数复杂化（thinking、reasoning_effort、max_tokens 互相耦合），改一个变量就可能让 prompt 输出全废。3 年前 API 只有一两家、参数很简单。

3. **开源生态只做了半块，完整闭环全在闭源** — DeepEval 做了评估指标，Promptfoo 做了测试，Langfuse 做了 tracing。但"改 prompt → 版本对比 → 看数据决定上不上"这条闭环，开源产品里还没有人做完整。

## UNDERLYING LOGIC

prompt 的问题不是"改 prompt 难"——改一个字符串谁都会。问题是改完之后你不知道发生了什么。一个 prompt 版本和下一个版本之间，缺少的是"可量化的对比"。

Prompt Lab 的机制是：把 prompt 从代码里的一个字符串，变成一个受控实验的变量。每次改动自动绑定版本，用固定的验证集跑两个版本，输出结构化对比报告（token 消耗、延迟、质量评分、输出 diff）。核心是让"改 prompt 好了还是坏了"从主观感受变成数据判断。

科学方法论三原则：
- **先定义理想态** — 改 prompt 之前先明确"好的输出"长什么样
- **控制单一变量** — 每次只改一个维度，否则不知道哪个改动起的作用
- **引入验证集** — 固定输入，保证对比的是 prompt 效果而非输入差异

## ANTI-POSITIONING

1. **不是 prompt 自动优化工具（当前）** — v1 聚焦"科学地对比"，让人用数据判断改好了还是改坏了。自动优化是未来可能的扩展方向，但不是起点——在没有版本管理和验证集基础设施之前，自动优化没有可以站立的基座。

2. **不是 LLM 可观测性平台** — 不做线上 trace 监控、实时告警、请求日志分析。那是 Langfuse / Phoenix 的事。我们聚焦的是"上线之前的决策"——改完了、对比完了、确认更好了，再上线。

3. **不是评估框架** — 不自己发明评估指标。DeepEval 已有 50+ metrics，直接用。我们做的是把评估包进对比工作流里，让跑评估、看对比、做决策变成一个连贯的动作。

4. **不是 SaaS 平台** — 开源工具，数据在开发者自己的机器上，不经过第三方服务器。

## 自检问题

**1. 晚宴上 30 秒怎么讲？**

"你改了 LLM 的 prompt，但不知道新版好不好。Prompt Lab 让你像跑 A/B 测试一样对比两个版本——固定测试数据，量化质量差异，用数据决定上不上线。"

**2. 最便宜的验证做过没？**

做过。EgoZone 的推荐 prompt 精简场景就是第一个真实用例：想砍掉 50% 的 prompt 长度，但没有验证集对比新旧版本的质量差异。手工跑了一次，但无法系统化复现。

**3. 世界要发生什么，才会让这个项目即使做得好也 FAIL？**

LLM 模型变得足够强，prompt 的措辞不再重要——模型在任何 prompt 下都能输出理想结果。如果模型完全消除了 prompt 敏感性，版本管理和对比就失去了意义。短期内不会发生，但这是长期风险。
